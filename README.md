# SELECT to Ship: MariaDB for Application Developers (book's companion repository)

This is the Git repository with the source code for the book [SELECT to Ship: MariaDB for Application Developers](https://selecttoship.com/) (ISBN 9798189773709).

## Structure

```
.
├── development-environment   <- if you want to quickly set up a complete dev environment with Docker
│   ├── docker-compose.yml
│   ├── extensions.sh
│   ├── mariadb-data
│   ├── mariadb.cnf
│   └── script.sql
├── README.md
└── workspace                 <- the actual examples one subdirectory per chapter
    ├── chapter-01
    ├── chapter-02
    ├── chapter-03
    ├── chapter-04
    ├── chapter-05
    ├── chapter-06
    ├── chapter-07
    ├── chapter-08

    └── chapter-10
```
